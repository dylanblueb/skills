# Make HTML

1. **用途**：用户明确要 HTML 时按要求生成；否则尊重指定格式，仅在排版、可视化或交互明显有益时建议用 HTML。简单内容优先单栏，遵循指定或已有风格。
2. **产物**：默认交付一个可本地打开的 `.html`，内联必要的 CSS、JS 和素材，不依赖 CDN、远程字体或构建工具。普通外链可以保留；联网功能须由用户明确要求，未经授权不上传或托管。保留理解内容所需的来源、单位和假设，不编造数据或来源。
3. **行为**：只为实际需求加 JS。禁用 JS 后，静态正文仍可读，不显示无法工作的控件。将不可信内容当作文本，不直接拼接进 HTML 或脚本。
4. **验收**：按预期交付方式打开最终文件，检查资源自包含、链接、语义结构、窄屏无整页横向溢出，以及关键交互的键盘操作和可见焦点。无法实测时做静态检查，并说明未实测。能写文件就交付 `.html`，否则给完整代码。
